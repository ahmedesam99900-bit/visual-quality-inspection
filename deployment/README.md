# Run Visual Quality Inspection

Launch `start_app.cmd` from the Windows project. The browser opens at `http://127.0.0.1:8765/`.

**Inspect** runs an active PCB1 or custom-product model. **Datasets** uploads labeled photos for a product. **Training** submits a local or GPU job and shows its progress. **Models** shows completed versions and allows activation. See the [project guide](../README.md) for setup and data requirements.
